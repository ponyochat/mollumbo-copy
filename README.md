# 몰름보 카피

크랙 스토리를 **항상 비공개로 복사**하고, 스토리 미디어를 구버전/뉴버전 형식으로 바꾸는 템퍼몽키 스크립트야.

## 설치

[몰름보 카피 본서버 설치하기](https://raw.githubusercontent.com/ponyochat/mollumbo-copy/main/stable/mollumbo-copy.user.js)

이 버전만 설치하면 돼. 새 버전이 올라오면 템퍼몽키가 업데이트를 확인해.

## 자동 업데이트 방법

- 사용자는 `stable/mollumbo-copy.user.js`만 따라가.
- 업데이트를 올릴 때는 파일 위쪽의 `@version` 숫자를 반드시 이전보다 크게 바꿔야 해.

## 중요한 안전 규칙

- 복사본은 코드에서 `private`으로 저장하고, 저장 뒤에도 비공개 상태를 다시 확인해.
- 미디어 버전 변경은 선택한 원본 작품 자체를 바꾸므로 확인창 내용을 꼭 읽어.
- 구버전 미디어는 제한 때문에 최대 50개만 남을 수 있어.
